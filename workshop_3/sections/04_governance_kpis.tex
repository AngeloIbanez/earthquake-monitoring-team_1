\section{Governance Summary and KPI Definitions}

Every governance metric in the Gold governance Parquet file (113 rows across 13 columns, $6.57\text{ KB}$) is justified directly by the Silver data quality findings in Section~III. Each row stores its category, metric name, agency scope, date, primary and secondary values, min/median/max quantiles, SLA threshold, PASS/WARN status, unit, and UTC timestamp. This uniform layout lets the Workshop~\#4 governance dashboard render every KPI card and chart from one Parquet file. Table~\ref{tab:governance_kpis} defines all six KPI families.

Two design choices make these governance metrics dependable in operations. First, even though curated Silver files show 0.00\% explicit nulls and 100.0\% schema compliance, keeping both metrics active serves as a continuous guardrail against upstream API changes. Similarly, tracking the 20.48\% intra-lake duplicate rate before deduplication confirms that overlapping Silver snapshots are cleaned reliably. Second, every outlier row stores $Q_1$, median, and $Q_3$ alongside the outlier rate so downstream dashboards can display statistical spread directly from Gold without scanning Silver files.
